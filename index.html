1. 動態陣列 (Dynamic Arrays)

Access: O(1) Insert/Delete: O(N)

📚 基礎觀念補給站

什麼是陣列？

陣列就像是一排連續的儲物櫃，每個櫃子都有編號（索引 Index）。

  • 隨機存取 (Random Access): 因為記憶體是連續的，電腦可以用公式 位址 = 起始點 + 索引 × 大小 瞬間找到資料，這就是 O(1) 的由來。
  • 靜態 vs 動態: 傳統陣列 (Static) 大小固定。動態陣列 (Dynamic) 當空間滿了時，會自動建立一個更大的陣列（通常是 2 倍）並搬移資料。

🎨 互動實驗室

💡 觀察重點：插入中間位置時，黃色方塊如何「集體搬家」。

💻 C 語言實作：插入邏輯


// 在 index 位置插入 value
void insert(int arr[], int *n, int index, int value) {
    // 1. 從最後面開始，將資料往後搬移 (Shifting)
    for (int i = *n; i > index; i--) {
        arr[i] = arr[i - 1]; // O(N) 的主因
    }
    // 2. 放入新資料
    arr[index] = value;
    (*n)++; // 更新大小
}

📝 隨堂測驗

1. 為什麼在陣列索引 0 插入元素最慢？

解析：在頭部插入 (i=0) 是最壞情況，因為需要移動 N 個元素。

2. 陣列的哪個操作是 O(1)？

解析：Get(i) 是 O(1)，只要知道索引就能算出記憶體位置。

2. 堆疊 (Stack) 與 佇列 (Queue)

📚 基礎觀念補給站

Stack (堆疊)

LIFO (後進先出)。就像疊盤子，最後放上去的盤子必須最先拿走。應用於函式呼叫堆疊、Undo 復原功能。

Circular Queue (環狀佇列)

FIFO (先進先出)。為了解決陣列實作 Queue 時前方空間無法回收的問題，我們讓索引「繞圈圈」，公式：(rear + 1) % size。

1. 若使用陣列實作 Queue，且不使用環狀技巧，移除(Dequeue)元素會有什麼問題？

解析：如果不循環使用，隨著 front 往後移，前面的空間就無法再寫入資料。

3. 鏈結串列 (Linked Lists)

Add Head: O(1) Search: O(N)

📚 基礎觀念補給站

Linked List 像是一場尋寶遊戲，每個節點 (Node) 都有兩部分：

  • Data: 寶藏本身。
  • Next Pointer: 下一個藏寶點的線索 (記憶體位址)。

優點是記憶體不需連續，且擴充容易；缺點是無法像陣列一樣直接跳到第 N 個位置，必須從頭開始找。

💻 C 語言實作：節點結構


struct Vertex {
    int item;            // 資料
    struct Vertex* next; // 指標：指向下一個 Vertex
};
// 記憶體是非連續的，靠 malloc 動態分配

📝 隨堂測驗

1. 在 Linked List 中搜尋第 K 個元素的時間複雜度是多少？

解析：Linked List 必須從 Head 開始順著指標走，無法直接計算位址。

4. 二元搜尋樹 (BST)

📚 基礎觀念補給站

BST 是一種特殊的樹，遵守嚴格規則：左 < 根 < 右。

這個特性讓搜尋變得非常快 (類似猜數字遊戲，每次都猜中間，排除一半)，平均只要 O(log N)。但如果樹歪一邊 (Skewed)，最壞會退化成 O(N) 的 Linked List。

📝 隨堂測驗

1. 在 BST 中，比根節點(Root)小的數字會放在哪裡？

解析：這是 BST 的定義，左邊永遠比根小，右邊永遠比根大。

5. 圖論基礎 (Graphs)

📚 基礎觀念補給站

圖是用來描述「關係」的結構，由頂點 (Vertex) 和 邊 (Edge) 組成。

  • BFS (廣度優先): 像水波擴散，使用 Queue。適合找最短路徑。
  • DFS (深度優先): 像走迷宮一條路走到黑，使用 Stack (或遞迴)。

📝 隨堂測驗

1. 實作 BFS (廣度優先搜尋) 通常使用哪種資料結構？

解析：BFS 使用 Queue 來記錄待訪問的鄰居節點，以保持「先進先出」的順序。
